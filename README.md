# MiCita Salud

## Descripción del proyecto
MiCita Salud es una plataforma web y móvil desarrollada para una IPS de la ciudad de Bucaramanga, orientada a la gestión de la agenda de citas médicas de sus sedes. El sistema permite a los pacientes registrarse, consultar disponibilidad, solicitar, cancelar y reprogramar citas; a los médicos consultar su agenda y registrar la evolución de las consultas; y al personal administrativo gestionar agendas, usuarios y reportes.

Este repositorio contiene el modelado funcional del sistema mediante diagramas UML de casos de uso, desarrollado como parte de la actividad académica del curso.

## Herramienta utilizada
El modelado del diagrama de casos de uso se desarrolló utilizando **Lucidchart**, una herramienta de diagramación en la nube que permite construir diagramas UML de forma visual, colaborativa e intuitiva, con soporte para las relaciones de asociación, generalización, «include» y «extend», y facilidad de exportación para su incorporación al documento final.
